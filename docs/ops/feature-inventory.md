# Feature inventory — what is sold, what works, what is hidden (G20-F1, 2026-09-20)

**Why this file exists.** G20 "Ready for sale" (`docs/plans/g20-ready-for-sale-2026-09-20.md` § 2): every feature a customer can reach either works end-to-end on production or is hidden. This is the ledger of that decision for every nav hub/tab, sidebar row, user-menu row and in-page CTA across the ten personas (`web/src/lib/nav/persona.ts`). The machine-readable half is `web/src/lib/features/hidden.ts` (`HIDDEN_FEATURES`), read by the hub-tab catalogue, the sidebar catalogue, the user menu, the admin sidebar, the mentor tab bar and `sitemap.ts`; `hidden.test.ts` proves every hidden route is absent from all of them and still answers the shared `NotOfferedCard` ("Not offered yet — talk to us", `noindex`). `no-placeholder-copy.test.ts` fails when "coming soon / not available yet / under construction / ships in a follow-up release / TODO:" reappears on a reachable page.

**Un-hiding** a feature = delete its row in `hidden.ts`, restore the page body from history (each hidden page's header comment names what it replaced), re-add the nav row if it was removed, and run `npx vitest run src/lib/features src/lib/nav src/components/workspace`.

**Env column** = key names only; `1`/`0` = whether `grep -c "^KEY=" web/.env` found the line on the production box on 2026-09-20 (values were never read). Supabase / Stripe platform keys are assumed present and not repeated.

Status: **working** = real backend, renders, no placeholder copy · **partial** = works with a caveat noted in Decision · **hidden** = in `HIDDEN_FEATURES`, answers the card.

Counts (rows below): founder 92 working · 5 partial · 9 hidden — evaluator 21 working · 1 partial · 5 hidden — accelerator 13 working · 1 partial · 2 hidden — reseller/mentor 15 working · 2 partial · 3 hidden — public tools/pages 34 working · 3 partial · 4 hidden — admin 44 working · 1 partial · 1 hidden.
