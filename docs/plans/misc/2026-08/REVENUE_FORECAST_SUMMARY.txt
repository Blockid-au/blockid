CALCULATION ENGINE
==================
Inputs:
  • Current ARR (AUD)
  • Monthly growth % (decaying S-curve)
  • Monthly churn %
  • COGS % of revenue
  • Monthly OpEx (escalating by scenario)
  • Fixed costs
  • Scenario multiplier (bear=0.7, base=1.0, bull=1.4)
  • Tax incentives flag (RDTI)

Outputs (36 months):
  • Month-by-month revenue, COGS, gross margin, OpEx, EBITDA
  • Cash flow analysis (outflow, cumulative burn)
  • Team headcount projection
  • Tax offset calculations (RDTI monthly)
  • Breakeven month
  • Series A funding gate month
  • Peak monthly burn
  • Runway in months

Key Logic:
  • Deterministic (no randomness, same inputs = identical output)
  • Growth decay: max(2%, baseGrowth - (month/6) * 1.0)
  • OpEx escalation: scenario-dependent (1-3.5% monthly)
  • Headcount ramp: scenario-dependent (hire every 2-6 months)
  • RDTI: 43.5% premium on eligible R&D spend (min A$20k/year)

================

  • churnPct: 0 ≤ x ≤ 100
  • cogsPercent: 0 ≤ x ≤ 100
  • opexMonthlyAud: 0 ≤ x ≤ 1,000,000,000
  • fixedCostsAud: 0 ≤ x ≤ 1,000,000,000

Warnings (non-blocking):
  • ARR=0 AND growth=0: "No revenue and no growth?"
  • OpEx > Revenue: "Monthly burn exceeds revenue"
  • Churn > Growth: "Negative unit economics?"
  • Growth > 50%/mo: "Hypergrowth assumption"
  • ARR > 10M: "Projected ARR very high"

Error Responses:
  • 400: Validation error (out of range)
  • 402: Insufficient credits
  • 429: Rate limited
  • 500: Server error (logged)
