### 4b. Data model (migration `0308_au_grants_programs.sql`)

### 4c. Agent — `web/src/lib/agents/grant-advisor.ts`

```
matchGrants(profile: GrantProfile, grants: AuGrant[]): ScoredGrant[]      // pure, no LLM
matchPrograms(profile, programs: AuProgram[]): ScoredProgram[]            // pure
buildTimeline(profile, scoredGrants, scoredPrograms, today): TimelineItem[] // pure — 12 months, ordered by close dates + lead time
narrateFundingPlan(profile, top: …): Promise<{narrative_md, actions[]}>   // callAI temp 0.4 (serial, like accelerator-drafter.ts:163); template fallback
generateFundingReport(input): Promise<FundingReport>                      // orchestrates above
```
Scoring (deterministic, 0-100): hard gates (state HQ, city for in-person programs, entity type, turnover, stage, affiliation, `status!=open`→excluded) → 0 if fail; then weighted: stage fit 30 · industry fit 25 · amount vs need 15 · demographic bonus 10 · timing (open now / opens ≤ 90 d) 20. Reuse `estimateRdti(RdtiInput)` ([`cfo-au-tax-incentives.ts:220`](../../web/src/lib/agents/cfo-au-tax-incentives.ts#L220)) / `evaluateEsic(EsicInput)` (`:433`) for the two tax items — they need `aggregatedTurnoverAud`, `eligibleRdExpenditureAud`, `yearsSinceIncorporation`, prior-year A$ figures, `listedOnExchange` → hence the numeric `project_grant_profiles`. LLM audit: `auditText()` ([`llm-auditor.ts:111`](../../web/src/lib/report-pipeline/llm-auditor.ts#L111)) takes an ADK `ModelCaller`, so wrap via `callAIToModelCaller` ([`agent-dispatcher.ts:302`](../../web/src/lib/report-pipeline/agent-dispatcher.ts#L302)); the narrative may only cite `ref_id`s that exist in the scored lists (`findUncitedClaims` guard). Colocated `grant-advisor.test.ts` pins scorer + timeline (test-gate requires it).

Timeline logic (per founder stage):
- **Idea / pre-revenue:** community + pre-accelerator first (0–3 mo) → university/state vouchers (2–6 mo) → accelerator intake (next cohort) → R&DTI registration once R&D spend exists → angel/ESIC.
- **MVP / early revenue:** accelerator or Industry Growth Program EIS (0–4 mo) → state MVP/commercialisation grants → R&DTI (register by 30 Apr following FY end) → EMDG if exporting.
- **Scaling:** IGP Commercialisation & Growth, EMDG, Export Finance, corporate programs → VC.
Each `TimelineItem = {month, kind:grant|program|tax|milestone, ref_id, action, lead_time_days, deadline, why}`.
