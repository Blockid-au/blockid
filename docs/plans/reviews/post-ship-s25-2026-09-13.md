### Verified OK (no finding)

- **Audit wrapper:** every mutating route in the range is `apiRoute()`-wrapped — `dividends/[recordId]/statements` POST, `[recordId]/data-room` POST, `statements/[id]/void` POST, `/api/revenue` POST, `/api/svi/rescore-from-evidence` POST. The PDF / register / list routes are GET-only.
- **Cron:** `api/cron/connector-resync` uses `isCronAuthorised()` (SHA-256 + `timingSafeEqual`), Bearer only; GET and POST both accepted (matches every other cron route); `?dry=1` returns before any write; 240 s budget under `maxDuration = 300`.
- **Scope / IDOR:** statements issue + data-room = `projectScopeOrDeny("editor")`; void = `"admin"`; reads = `"viewer"`. `getDividendRecordForScope()` pins `account_id = ownerUserId` **and** `project_id` (null on mismatch, never 403 → no id oracle); `getStatementForProject()` pins `project_id`; `listStatementsForRecord()` pins both. `isUuid()` guards every param.
- **Outbound fetches:** fixed hosts only — `https://api.stripe.com`, `https://api.xero.com`, `https://identity.xero.com`. No user-supplied URL reaches `fetch`.
- **Tokens:** read only via `openToken()`; Xero rotated pair written back through `sealToken()` on both vaults; summaries carry row ids + outcome only; the resync suite pins that no console line contains the sealed or raw bytes (and now also for the 401 / 429 / Xero-403 paths).
- **Money:** `TFN_WITHHOLDING_RATE = 0.47`; franking credit = franked × r/(1−r) using the *exact* multiplier (30/70 at 30 %, 25/75 for a base-rate entity), `roundCents` on every A$ figure, `totals.ok` re-adds the parts and the PDF prints a rounding warning when they do not; `companyTaxRate` comes from `dividend_records.franking_rate` (which `calculateDividends` stores as the tax rate). Credits: preview → `canAfford` → `confirm: true` → `spendCredits` (`spend_credits_atomic`) **before** the insert, refund via `grantCredits("refund")` on total failure; idempotent per `(record, shareholder_key)` through the partial unique index `uq_dividend_statements_live`; void is an UPDATE (`voided_at`, `void_reason`, `dividend_statements_void_pair` CHECK) — the row and the credit ledger survive.
- **Contribution table:** `mrrTier` clamps non-finite / negative to 0; `growthPct` returns null on missing or non-positive prior (no NaN); decay 1 / 0.5 / 0 by age; `points = max(0, round(...))`.
- **Lease:** `claimConnection()` is a conditional UPDATE (`resync_leased_until IS NULL OR < now`) and only wins when a row comes back; `MAX_CONNECTIONS_PER_TICK = 20`; `RESYNC_MIN_INTERVAL_DAYS = 6`; per-connection errors are caught inside `resyncConnection()` (never abort the batch); `connector_reconnect` notification deduped per row with a 30-day throttle; Xero without a refresh token → `needs_reconnect`.
- **Migrations:** 0349 / 0350 / 0351 are idempotent (`IF NOT EXISTS`, `DROP POLICY IF EXISTS`, `DO $$ … IF NOT EXISTS`), RLS enabled with owner-SELECT policies, `NOTIFY pgrst`. 0351 = 0348 + header + one VALUES row (diffed).
- **UI:** dividend panel has loading skeleton, error card, `role="alert"` inline errors, AU English, "General information only, not tax advice" line; statement PDF entity block is the **founder's** company (`project_grant_profiles` ABN/ACN → SVI-form ABN fallback), BlockID appears only as the tool in the disclaimer; no `any` in either client.
