## 1. Evidence (from the audits, verified 2026-09-20)

- `SVISubScore` has `evidence: string[]` prose and a dimension `adjustment` but no per-signal points; the TBR drops `subs[].evidence` (`adapter.ts:937-948`), the owner agent gets boolean bags only (`agent-dispatcher.ts:1286-1316`); `riskPenalties`, `evidenceGaps`, `proposedScore/scoreNote`, `quality.consistencyIssues` are never rendered in `components/tbr/v2/*`.
- Pre-revenue valuation: 4 of 5 methods = Berkus × {1, 1.5, 1.1, 1.2} (`cfo-valuation.ts:562-586`); `monthlyGrowthRatePct` silently defaults to 10 %/mo (`:539`); confidence floor 45 % via an unconditional +10 (`:606`); raise invented as `blendedMid × 0.2` (`:615`); `unitEconomics`, inputs never rendered; no backtest hook.
- No dimension is ever "unassessed": baselines FTV/MPC/PTD 50, TRE 30, CGH/IRI/LCO 40 (`svi-analysis.ts:996-1195`); `band:"pending"` dead for real runs.
- Four "+N points" models (evidenceGaps, nextActions, `EVIDENCE_CATALOG`, `expectedLift = weight×(70−score)/100` → "+1" everywhere).
- Pipeline reads account-scoped `svi_evidence`, never project-scoped `svi_dimension_evidence` (`run-for-project.ts:338`); missing-row hints stored in `EvidenceRow.value` are not rendered; `moneyOnTable` never mapped from gather (`orchestrator.ts:1053`).
- Stage decided three ways (SVI stage 0–7, `inferPhase`, `navPhaseFromSvi`); dashboard has no strengths/weaknesses/value; cover `cohortPercentile` always null.
- Paid A$3 lands on `/workspace/reports/order` = markdown + legacy PDF/DOCX (`ReportOrderView.tsx`, `unlock-rail.tsx:99`).
- Demo report: 1,705 words, ~40 % boilerplate; "Register ABN" for a Verified-ABN company; Money A$0; auditor "not yet audited" ×10; VI = ASCII-stripped headings over English internals; no clarity survey.

## 3. Decisions
- D1 Scores stay 0–100 per dimension and open-ended SVI; the ledger explains, it does not change the formula (except: unassessed dimensions render pending — their baseline still feeds the total until data arrives, and the cover says how many dimensions are pending).
- D2 One lift model = `EVIDENCE_CATALOG.estimatedSviImpact`; LLM `expected_lift` is clamped to it.
- D3 Pre-revenue valuation = Berkus (0.5) + scorecard (0.3) + stage baseline (0.2) with the band widened by confidence; revenue methods only with ARR > 0 and a connector or document source.
- D4 The paid product is the ReportV2 page; `/workspace/reports/order` becomes a thin wrapper. Legacy markdown report stays reachable for old orders.
- D5 Phase = `inferPhase(declared, criteria, dims)` everywhere; SVI stage 0–7 is internal (benchmarks only), never shown beside the 12-phase label.
- D6 Clarity survey question (EN/VI): "Was this report clear and useful?" 0–10; KPI median ≥ 8.5, N ≥ 30/month.
