## 0. Strategic decision (from the advisor feedback, stripped of course context)

Do **not** pivot the product; **simplify the market entry.** BlockID = *evidence-backed startup assessment infrastructure* for accelerators, innovation programs and professional evaluators; founders remain the data owner, participant and secondary paying customer. The commercial wedge is **one paid cohort pilot at A$1,500+**. The moat is **evidence + methodology + verification + comparability + longitudinal history + institutional workflow** — never "our AI is better".

Adopted in full: clearer problem statement · primary buyer = organisations with repeated intake volume · A$3 no longer the headline anchor · trust is the product (one legal identity, visible methodology version, provenance, labelled unverified claims, audit history, founder-controlled disclosure) · "ChatGPT analyses what you paste; BlockID maintains a structured evidence-backed company record and applies one methodology across every company and every point in time" · validation = real payment. Adopted partially: marketplace = later; angels = secondary; external datasets = optional connectors; founder execution = evidence-only inside Founder & Team. Not adopted: brand change; investor-only product.

Four layers (already mostly built — this goal makes them **visible and consistent**): L1 Business Identity (Verified Business Profile) → L2 Evidence Graph (Claim ≠ Evidence) → L3 Assessment Engine (SVI, 8 dimensions, each with score/weight/confidence/evidence/missing/benchmark/action) → L4 Decision & Progress Infrastructure (dossier, cohort, benchmark, sponsor report, export, API, decision log).

Naming (sub-products, no new inventions): **BlockID** · **Startup Value Index™** (methodology) · **BlockID Dossier** (evaluator output) · **BlockID Cohort** (program workflow) · **BlockID Workspace** (founder) · **BlockID Verified** (verification state). Trusted Business Report keeps its name (it is the A$3 SKU, not a hero product).

Three messages everywhere: **Screen faster · Trust the evidence · Track improvement.**
Institutional message: **BlockID structures the evidence and standardises the first-pass analysis. Humans make the decision.**

## 3. Cross-cutting rules for every phase
1. **Order inside a phase:** lanes run in parallel worktrees (`EnterWorktree` / Agent `isolation:"worktree"`), each commits on its branch; the session merges (lanes never touch each other's files — ownership above is binding; shared files get a one-line hook owned by one lane), runs full `npm test` (unit + pdf) + `tsc` + `eslint`, then `bash scripts/deploy-live.sh --wait` (12 gates), then `LIVE_QA_ALLOW_DB=1 LIVE_QA_ELEVATE=1 bash scripts/qa-live.sh`, `node scripts/link-check.mjs`, `node scripts/page-sweep.mjs`, then a read-only **code-reviewer + security-audit** agent on the phase diff, then fixes → deploy again if needed → version bump + CHANGELOG + `/version` + SOT status line + ROADMAP row + memory.
2. **Copy rules:** messaging map + never-say guard; claims register (proven / observed / hypothesis) for every number; no "AI decides", no accuracy claims, no "Australian average" without n, no agent counts in public copy, no A$3 in hero/nav/OG/pitch; entity from `LEGAL_ENTITY` only.
3. **Data rules:** projects-only FKs; RLS on every new table; consent scope honoured on every evaluator read; corrections and overrides are appended, never overwrite; audit row on every status change.
4. **Deploy rules:** serialize behind the peer (`flock`), never remove zero-commit worktrees, `scripts/cleanup-merged-worktrees.sh` after merge, `DEPLOY_DIRTY_IGNORE` unchanged, migrations by hand + ledger JSON committed.
5. **Pricing rules:** the sold ladder (G18) is unchanged except the new one-off pilot SKUs; price literals only in constants + catalogue; Stripe prices for the pilot are **minted by the founder** (`scripts/stripe/seed-stripe.mjs` rows added, not run) — until then the pilot CTA falls back to the contact form and live-qa asserts the fallback.
