# G17 — Unicorn homepage & site template: evaluator-first hero, one design system, no pricing on home

**Opened:** 2026-09-19 (founder: modern "unicorn startup" homepage, very clear hero for the investor ladder, short and easy to grasp, no price tables on the homepage, one consistent template for the whole site, keep the search box with the colour-changing border, move the complex material into the intro menu / sample-result pages; use the ui-ux-pro-max skill; every link must work; deploy live, review, fix automatically).
**Owner:** Claude session loop — Phase 1 (design system + chrome + homepage) → merge/deploy → Phase 2 (template roll-out to every marketing page ∥ link + content QA) → merge/deploy → review → fix → close.
**Tracked in:** `docs/plans/SOURCE-OF-TRUTH.md` § G17.

## 1. Research (ui-ux-pro-max, 2026-09-19)

- Pattern: **Minimal single column** — single CTA focus, large typography, lots of whitespace, no nav clutter, mobile-first; sections = hero → short description → ≤ 3 benefits → CTA → footer. Landing variant "Hero + social proof + CTA" (proof *before* the second CTA).
- Style: **Flat / modern SaaS** — no gratuitous gradients or shadows, one elevation scale, 150–200 ms transitions, SVG icons only (Lucide, already in use), light mode default with a full dark pairing (the skill's dark fintech palette is rejected as default: "Dark mode by default" is an anti-pattern here and the current brand is light).
- Typography: **Space Grotesk** headings + **Inter** body (both already loaded via `next/font` in `app/layout.tsx`; `IBM Plex Mono` stays for figures). Type scale 14/16/18/24/32/48/64, body 16 px, line-height 1.5–1.6, tabular numerals for scores/prices.
- Colour: keep the blue brand (`--color-brand-600 #2563eb`) as **primary**, add one **accent** for the "unicorn" energy: violet `#7c3aed` used only in the search ring gradient, the hero eyebrow and focus rings; neutrals slate (`ink`/`surface` tokens already exist in `globals.css`/`tailwind.config.ts`). Contrast ≥ 4.5:1 everywhere; buttons 7:1.
- Anti-patterns to remove from today's home: 6 stacked sections (worth / state / journey / next / runs / tiers / trust / final CTA / unlock preview — 448 lines), two audiences competing in the hero, a price ladder on the home, emoji-free but icon-dense tables, copy that assumes the reader knows "SVI".

## 2. Design decisions (defaults ship if the founder is silent)

- **D1 Audience & message.** Hero speaks to the **evaluator ladder first** (investors → accelerators → advisory firms) with founders as the second line, matching G14 positioning ("Startup Value Index … by BlockID"). H1 (≤ 9 words): *"Score any Australian startup in 60 seconds."* Sub (≤ 22 words): *"One rubric for every deal — eight dimensions, an evidence-backed valuation range and an Investor Dossier. Investors, accelerators and advisors use it; founders get the feedback free."* Primary CTA: **"Score a startup"** (→ the search box / `/analyze`). Secondary: **"See a sample dossier"** (→ `/tbr/demo`). Founder line under the box: *"Founder? Get your own score free."*
- **D2 The search box stays** — `AnimatedSearchFrame` (rotating conic ring) is the one signature effect; re-tokenised to brand→violet, `prefers-reduced-motion` freezes it.
- **D3 Homepage = 6 blocks, ≤ 1 screen each on desktop:** (1) hero + search, (2) "Who it's for" — three cards Investors / Accelerators / Advisors, one sentence + one link each (`/solutions/investor`, `/solutions/accelerator`, `/solutions/advisor`), (3) "How it works" — 3 steps with one Lucide icon each (Paste a name or deck → 8-dimension score + valuation range → Dossier, cohort table, feedback letter), (4) **one sample result** — a real dossier card (score, valuation range, top risk) rendered from the existing fixture, linking to `/tbr/demo` and `/sample-business-report`, (5) proof strip — four numbers from live data (`/api/platform-stats`: startups scored, register signals 25,955, backtest ρ 0.76/0.94, evaluator orgs) + logo band, (6) final CTA + footer. **No price tables, no tier ladder, no unlock preview on the home.** Pricing lives only in the nav ("Pricing") and `/pricing`.
- **D4 Intro menu.** The removed depth moves to **`/product`** (new "intro" page: what the score is, the 8 dimensions radar + table, valuation ranges, the journey ladder, data-room build, sample-run comparison — i.e. the existing homepage components, unchanged, re-homed) and to **`/samples`** (new: the sample runs gallery). Nav: **Product · Solutions · Samples · Pricing · Docs** (+ Sign in, "Score a startup"). Mobile: same five in the sheet. Legacy anchors (`/#worth`, `/#state`, `/#tiers`, `/#trust`) redirect to `/product#…` / `/pricing` via `legacy-redirects.ts` rows (live, tested).
- **D5 One template for every marketing page.** `components/marketing/template/*`: `PageHero` (eyebrow, H1, sub, ≤ 2 CTAs, optional visual slot), `Section` (eyebrow + H2 + lede, `max-w-6xl`, 96/64/48 px rhythm), `FeatureGrid`, `StatStrip`, `ProofBand`, `CtaBand`, `Prose` (long-form), `Faq`. Every page under `(marketing)` uses them; no page-local hero markup remains. Footer: 4 columns (Product, For, Company, Legal) + entity line (PPL Food PTY LTD marketing / Auschain billing per the entity rule) + language switch.
- **D6 Tokens.** `globals.css` `@theme`: add `--color-accent-*` (violet), `--radius-*` (8/12/16/24), `--shadow-1/2` (two levels only), motion tokens (`--dur-fast 150ms`, `--dur-base 200ms`, `--ease-out`). Dark mode pairs defined under `prefers-color-scheme: dark` + `[data-theme]`. No raw hex in components.
- **D7 Every link works.** A link checker runs in CI-less fashion: `scripts/link-check.mjs` crawls the built site (or production) for every `<a href>` on marketing pages, follows internal links, fails on 404/5xx/redirect loops, allow-lists external hosts; gate 12 smoke gains a homepage hydration + CTA-navigation test; `menu-structure.spec.ts` updated to the 5-item nav.
