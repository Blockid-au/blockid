# G30 V01 — submitted financial context, without valuation admission

The trusted recurring-revenue producer registry remains empty. No submitted number, URL, model output or source quote is added to that registry or passed into CFO valuation inputs by this change.

A deterministic limited input check now retains up to three explicitly labelled financial lines (MRR, ARR, revenue or GMV; English labels), optionally prefixed with the exact business name. Each record keeps the exact received text span, full-input SHA-256 identifier, report owner/project/business scope, currency/period markers and forecast marker. No amount is parsed, rounded, annualised, converted or treated as independently verified. Bare currency symbols, unbound business identity, absent periods and projections produce explicit requests. Currency/date markers are text observations, not validated financial periods or legal-entity attestation. The full original quote preserves units. The source is the submitted report input, not proof of the original uploaded file or a bank/accounting record. Arbitrary URL digits, competing-business lines, industry totals and funding asks are not relabelled as this business's revenue.

Gather previously stored a detailed unavailable reason but returned only `missing_or_invalid_revenue` to the canonical report adapter. It now returns the input-specific explanation, exact reported quotations and missing-input requests, while MRR/ARR remain null, the CFO builder remains skipped and qualified revenue evidence IDs remain empty. No new numerical valuation or fair-value claim is introduced. Missing data remains distinct from zero revenue; reported GMV/forecasts/one-off sales do not become recurring revenue.

Initial scoped evidence: 54/55 tests passed; one preexisting assertion expected the replaced generic reason and has been corrected. Added an integration regression for exact quotation propagation with no CFO admission. Final checks were paused for the root production dependency snapshot; no claim of a final green suite until root reruns with a private Vitest cache. No paid inference, live writes, migration or deployment performed by this task.

Limits: this is not general financial table extraction, Vietnamese metric-label extraction, source-file/page attestation, authenticated connector validation, accounting reconciliation, FX, valuation-method qualification or readiness to enable financial estimates. Long/complex/unlabelled lines may not be captured; the reason describes the limited check rather than claiming no financial data exists anywhere.
