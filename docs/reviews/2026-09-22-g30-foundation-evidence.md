## Integration blocker reported during this review

Independent reviewer `/root/release_safety` traced an upstream partial-deck purchase path: `pitchdeck-analyze-client.tsx` calls `/api/pitchdeck/analyze`, whose route debits before returning selected dimensions; the client then forwards those dimensions with deck text to the stream. With 1–7 selected dimensions the new stream guard rejects only after that earlier debit. The runner/stream no-debit tests cover their own boundaries, not this earlier endpoint. Root has been notified. Release acceptance must resolve this path before claiming that rejected partial document requests never charge: enforce the same contract before the upstream debit and provide a clear full-analysis UI path, or implement a complete first-pass contract. This evidence note does not mark it resolved.

- [DeepInfra structured outputs](https://docs.deepinfra.com/chat/structured-outputs) support schema/JSON modes; schema compliance does not prove factual correctness.
- [Prefix caching](https://docs.deepinfra.com/chat/prompt-caching) is automatic for matching prompt prefixes on the same model. Stable shared instructions may help, but realized savings require usage measurement.
- [Batch processing](https://docs.deepinfra.com/batch/introduction) was documented as a 20% discount with completion within 24 hours at the recheck. Consider for non-urgent evaluation/enrichment, not interactive promises.
