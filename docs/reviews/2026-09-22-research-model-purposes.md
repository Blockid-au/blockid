# Scoped research model purposes — source implementation

The existing internal `/api/investor-portal/ai-generate` now recognizes `research_synthesis` and `research_grounded_review`. Both require the existing shared token and remain **disabled by default** unless `SVI_RESEARCH_MODEL_EXECUTION_ENABLED=1`. This flag must remain unset until durable job/lease/customer-consent authority and provider model-budget reservation are wired and reviewed. A shared caller token alone is not spend consent.

Research requests use the existing `blockid-report-v1` DeepInfra dispatcher. The server rejects oversized research prompts rather than truncating evidence: system12,000 characters, user60,000. It caps synthesis at6,000 output tokens, review at4,000, and both at20seconds of dispatch budget. It makes one `callAI` invocation and disables the proxy's extra JSON repair call. Invalid JSON, oversized response text, or missing scoped DeepInfra policy are rejected. Successful responses attest the requested purpose; research error responses omit raw provider details. General report requests retain their previous policy, ceilings and JSON-repair behavior.

These controls bound prompt/output size and wall-clock execution, **not dollars**. The existing DeepInfra dispatcher may internally try multiple eligible models within that deadline. A production model-budget coordinator must conservatively reserve for permitted underlying attempts and reconcile ambiguous outcomes before this flag is enabled. The companion SVI adapters call a required trusted authorization callback separately before synthesis and review, but its caller must implement genuine durable authority/budget consumption; returning a UID or boolean is insufficient. No flag, environment, quota or provider account was changed here.

Seven route tests pass, covering prior report behavior, configured authentication, default-disabled research, missing secret, evidence-size rejection, purpose attestation, task/token/deadline caps and no research JSON retry. All model calls are mocked. No provider calls, deployment or paid activation occurred.

## Per-attempt admission (source only, execution remains off)

`AICallOptions.attemptBudget` is a server-owned durable coordinator seam in the actual DeepInfra ladder. The two research agent IDs require this hook and `blockid-report-v1` before any gateway/provider I/O. The existing HTTP gateway deliberately supplies no hook yet, so setting its purpose flag alone cannot authorize research spending. Legacy calls without the hook retain their existing behavior.

Each actual model dispatch reserves independently using SHA256 of the durable call identity, fixed provider, model and exact serialized payload hash. The caller must bind `callId` to the original authorized job/purpose/review batch and persist it across retries, never regenerate it from a clock. The coordinator must atomically count the maximum cost before permitting dispatch and deny replay, including across concurrent workers. A permit binds the request digest and model, certified input/output token and prompt-byte ceilings, positive maximum microUSD, price policy identity and expiry. No static price map admits research spend. The coordinator must certify the exact payload's input-token ceiling using trusted model context/token accounting and current approved prices; a shared API token is not that authorization.

Reserve/settle wait at most five seconds. A timeout may complete a durable write later; no provider call is allowed after reservation timeout. Unknown transport, malformed/missing usage and failed settlement retain the maximum reservation for reconciliation. Valid provider usage is forwarded to the coordinator, which alone can reconcile against its certified price policy. Over-ceiling usage and budget denial terminate the call without falling through to another model/provider. Each admitted attempt has a single transport: unexpected direct transport failures no longer silently invoke subprocess retry for budgeted calls. The upgrade/free fallback entry point also rejects research calls.

No durable model budget coordinator, grant issuer, authenticated worker-to-gateway admission context or live price policy has been activated by this patch. Do not enable execution until those are wired and tested. Existing legacy spend telemetry is not the authority for reservations or refunds.

Validation: integrated dispatcher tests exercise denied second model after ambiguous first dispatch, retained first reservation, separately admitted retry, stable replay identity, hidden transport retry suppression, missing hook, malformed permit, missing usage and terminal settlement failure. Helper tests cover coordinator timeout and token-ceiling breach. The full dispatcher suite's existing G29 unfunded-account date fixture fails identically with pre-change `ai-client.ts`; the scoped G30 tests pass. Full-project type checking was stopped to release RAM for the independent live promotion; it is not claimed complete.

## Remaining quality prerequisites before research activation

- Batch grounded review (about 12 material claims per batch), with exact union of all required claim verdicts and a cumulative authorized call/cost cap. Current 60-claim / 4,000-review-token limits can reject normal five-competitor comparisons; raising limits alone is insufficient.
- Produce an explicit capacity/coverage outcome for the 60,000-character model input limit versus up to 1.8MB accepted snapshots. Never silently truncate evidence or describe capacity failure as no evidence.
- Distinguish exhausted budget, replay requiring reconciliation and provider unavailability from a successfully empty search (which cannot establish absence). Partial-search limitations must identify incomplete coverage without exposing raw errors/private queries.
- Bind original deck/input evidence to the authenticated creator/current report revision and source hash, label it management-provided, and assess it alongside independent market sources. Prior AI narrative or brief metadata is not original deck evidence.
