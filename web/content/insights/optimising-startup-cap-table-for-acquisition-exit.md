## Key Insight

A clean and optimised cap table is essential for attracting investors and ensuring a successful M&A exit. **ESI and ASIC regulations** require accurate and up-to-date cap table management.

| **Cap Table Component** | **Description** | **Best Practice** |
| --- | --- | --- |
| Share classes | Define different types of shares | Use a single, standardised share class |
| Shareholders | List all shareholders and their stakes | Regularly update shareholder records |
| Options and warrants | Account for outstanding options and warrants | Include in cap table calculations |
