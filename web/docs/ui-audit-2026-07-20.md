# UI/UX polish pass — 2026-07-20

Surgical audit of the 9 surfaces shipped in the hero + workspace refresh.
No redesign; no new components; no new routes.

## Fixed

### 1. Invisible text on Term Sheet history (severity: critical)
`text-ink-8000` is not a Tailwind token — it silently rendered no color, so
the table header and the "General information only. Not legal or financial
advice." disclaimer were both invisible against `bg-white`.

**Why it matters** — the disclaimer is a compliance requirement (AFSL /
general-advice framing). An invisible disclaimer is a legal exposure.

Files:
- `web/src/app/workspace/term-sheet/page.tsx` — disclaimer → `text-ink-600`
- `web/src/app/workspace/term-sheet/term-sheet-history-client.tsx` — thead → `text-ink-600`

### 2. Edit / Archive unreachable on touch (severity: high)
`/workspace/projects` cards used `opacity-0 group-hover:opacity-100` on the
secondary action row. Touch devices have no hover state, so mobile users
could not edit or archive a startup at all.

Fix: always visible under `sm`, hover-only from `sm` up; also honors
`focus-within` so keyboard users can see the row without a mouse.

File: `web/src/app/workspace/projects/projects-client.tsx`

### 3. Missing AFSL disclaimers on new financial surfaces
Per memory rule: every valuation / financial surface must carry "General
information only. Not financial advice."

- Idea Clarify recommendation card now shows the disclaimer under the
  primary CTA (`web/src/app/tools/idea-clarify/idea-clarify-tool.tsx`).
- Per-project SVI analyzer header now carries the disclaimer above the
  form (`web/src/app/workspace/projects/[slug]/analyze/page.tsx`).

Fundraise + Term Sheet + SVI results already carried it — no change beyond
the visibility fix in #1.

### 4. Loading copy that doesn't say what's happening
Fundraise step 0 had `Loading readiness checklist...` and
`Loading past rounds...` in low-contrast `text-ink-400`. Replaced with
higher-contrast `text-ink-600`, tightened copy (e.g. "Scoring investor
readiness against your SVI signals…"), and wrapped in
`role="status"` + `aria-live="polite"` so screen readers get progress.

Admin pricing-test "Creating…" was text-only; added a spinner + accessible
alert region for the feedback banner.

Files: `web/src/app/workspace/fundraise/fundraise-client.tsx`,
`web/src/app/admin/pricing-test/pricing-test-client.tsx`.

### 5. Tap targets < 44px and missing focus rings
- Term Sheet history delete button was `h-8 w-8` (32px). Now `h-11 w-11`
  on mobile, `h-9 w-9` from `sm` up. Added `focus-visible:ring-offset-1`
  so the ring doesn't clip the border. Icon color bumped from
  `text-ink-400` → `text-ink-500` for AA contrast on white.
- `Run SVI Analysis` link on project cards had no `focus-visible` ring
  and no minimum height. Added `min-h-11` + ring.
- Header `Create New Startup` and `Upgrade for More Startups` on
  `/workspace/projects` gained `min-h-11` + `focus-visible:ring-*`.
- Idea Clarify primary CTAs gained `focus-visible:ring-*`.
- Pricing-test `Create experiment` gained `min-h-11` + ring.

## Deferred

- **`text-ink-8000` elsewhere.** The typo also appears in
  `save-founder-pack-modal.tsx`, `/s/p/[slug]/page.tsx`,
  `/s/i/[token]/page.tsx`, and `score/score-form.tsx`. These sit outside
  the 9-surface scope of this pass. Worth a follow-up sweep — a single
  find-replace would clean the lot.
- **SVIEntrance (~2130 LOC).** Multiple competing primary CTAs on the
  same view (`Get My SVI — Free`, `Start Your Journey`, `Explore Platform`,
  `Sign In & Get 5 Free Credits`, Deep Dive banner, etc.). Deferred:
  a proper cleanup needs a design pass, not a polish edit; and this file
  is the busiest cross-owned surface in the repo.
- **Vietnamese localisation on hero + analyzer.** No single-string swap
  exists — VN strings would need to be added to a locale file that
  doesn't yet exist. Out of scope for a UI polish pass.
- **Hero-search AFSL disclaimer.** The hero navigates to `/svi`; it does
  not itself produce a financial output. Disclaimer already lives on the
  results view. Adding one to the hero would compete with the search
  affordance without adding compliance value.
- **Contrast pass on `text-ink-400` usage across SVIEntrance.** Many
  small labels sit at `text-ink-400` on white (~3.2:1). AA-borderline
  but pervasive; a systematic pass belongs in a design-token cleanup,
  not this surgical pass.
